# openvols
OpenVols is an open source multi-tenant volunteer management platform

# About
This project is under active development, started in August 2026 as a side project
to replace the website for [Front Range Trails Conservancy](https://frtrails.org/).
I created FRTC in 2022 and threw the site together to share our project dates
with the community, but never really finished it. It doesn't support any actual
registration, just the dates and details, and you email me to signup.

I'm designing this project based on my experience finding and coordinating
volunteers, and want not only to solve my own problems but to provide a place
that can help other leaders. I've talked to leaders of other similar groups
and no one really likes the platform they use, and a lot of volunteers don't
like the platforms on the other end of it. This is designed in a way that
it can support multi-tenancy because I have some aspirations of hosting it
in a way that groups can use it without maintaining anything of their own,
and it'll be as easily configurable to run for an individual organization,
such as my own.

Overall, it's a bit of a fun project to help what I do on the weekends,
but also one I take seriously as an experienced engineer wanting to provide
great software.
